# 多助手总管协作（chief-coordinator）

把「总管」的接单、分工、跟踪、提醒去重、周报、档案分层、按需同步和省额度协作写成可复用技能。这是一份流程模板，使用时再填入当前团队的角色；它不绑定具体助手名、账号、标识、个人或案件资料。它不替代所用平台的权限、草稿确认与审批规则。安装本技能不会自带任何自动化、代码、依赖、例程或数据。

## 安装

1. 将本目录中的 `SKILL.md` 作为技能正文。
2. 若在支持技能库的产品中安装，用技能更新接口写入：
   - `name`: `chief-coordinator`
   - `description`: 见 `SKILL.md` 文首 YAML
   - `body`: `SKILL.md` 中 YAML 分隔线之后的正文
3. 本目录是文稿，不自行新建仓库；保存到已有仓库或技能库时，按用户已提出的保存要求与平台规范处理。

## 使用示例

在需要总管协调多个助手时加载本技能，先填写「角色配置」，再按原则执行。

- 用户说「把这些任务分给合适的人并盯进度」：先核对分工授权，再按「接单与分工」「任务进度」执行；已授权且可逆的事项直接做，只在有实质进展或需要决策时回报。
- 用户说「每天提醒我，做完要记下来」：可按平台规范设置周期提醒并检查原例程是否重复；先真正发出提醒再记已发送，收到完成确认后取消同期重复催促。
- 用户说「怎么少消耗一点额度」：给出精简方案并说明影响，取得明确同意后再通知对口负责人修改。

## 注意

- 平台权限优先。规划、沉默、未答或关闭的选择卡都不是改设置的许可；省额度调整须经用户同意。
- 对外发送须遵循平台草稿确认，不能用一句笼统同意跳过必要审批。
- 公开发布须脱敏；私密笔记和事先授权的共享范围可以保存用户授权的内容。访问权按用户授权的角色划分。
- 联系方式、凭据和支付资料按平台规定放入安全存储，不写入普通档案、笔记正文、周报、进度记录或技能正文。
